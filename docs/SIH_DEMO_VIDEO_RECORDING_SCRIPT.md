## 🛠️ Step 0: Recording Setup Checklist (Before Pressing Record)

1. **Start the Application:**
   * Make sure Frontend is running (`http://localhost:3000` or `127.0.0.1:3000`).
   * Backend is running (`http://localhost:8000`).
2. **Browser Display:**
   * Open the app in Chrome / Edge.
   * Press **`F11`** to make it **Full Screen** (hides tabs and bookmarks for clean professional look).
   * Zoom level: `100%` or `90%` (for high density).
3. **Screen Recorder:**
   * **Windows Shortcut:** `Win + Alt + R` (Windows Game Bar) OR OBS Studio / Clipchamp.
   * Ensure Mic is enabled and test 5 seconds of audio first.
4. **Mouse Pointer:**
   * Move mouse smoothly, don't shake or rapidly click. Hover gently over cards/buttons to show hover animations.
