DEPLOYMENT WORKFLOW
================================================================

STEP 1: On Internet-Connected Machine
────────────────────────────────────────
$ cd A.E.G.I.S
$ .\scripts\prepare_offline_dependencies.ps1
# Creates: wheels/ directory with all .whl files

STEP 2: Transfer Project to Air-Gapped Machine
────────────────────────────────────────────────────────────────
- Copy entire A.E.G.I.S/ directory
- Copy wheels/ directory
- Use USB drive or external media (no network)

STEP 3: On Air-Gapped Machine - Install Dependencies
────────────────────────────────────────────────────────────────
$ cd A.E.G.I.S
$ .\scripts\install_offline_dependencies.ps1
# Installs all packages from local wheels (no internet)

STEP 4: On Air-Gapped Machine - Set Up PostgreSQL
────────────────────────────────────────────────────────────────
$ .\scripts\setup_postgresql_offline.ps1
# Creates database and user, verifies connection

STEP 5: On Air-Gapped Machine - Configure Environment
────────────────────────────────────────────────────────────────
$ Copy-Item .\backend\.env.offline .\backend\.env
# Update DATABASE_URL if PostgreSQL password differs

STEP 6: On Air-Gapped Machine - Install Frontend Dependencies
────────────────────────────────────────────────────────────────
$ npm install
# Or: pnpm install

STEP 7: On Air-Gapped Machine - Start Services (3 terminals)
────────────────────────────────────────────────────────────────
Terminal 1:
$ .\scripts\start_backend.ps1
# Backend runs at http://127.0.0.1:8000

Terminal 2:
$ .\scripts\start_frontend.ps1
# Frontend runs at http://127.0.0.1:3000

Terminal 3:
$ .\scripts\check_health.ps1
# Verifies both services are working

STEP 8: Verify Deployment
────────────────────────────────────────────────────────────────
- Frontend accessible at http://127.0.0.1:3000
- Backend API at http://127.0.0.1:8000/api
- Health check at http://127.0.0.1:8000/api/health
- Upload data and run analytics
